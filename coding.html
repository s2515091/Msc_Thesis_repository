Seven of the 23 questions decide the result. This page gives what each of their answers counts for. The other sixteen questions describe the project and have no score. The answer “I am not sure / not decided yet” counts as unanswered for every question. The full questions are on the questions page.

Governance mode

Each answer below is scored +1 where it points to the federated (decentralized) pole, −1 where it points to the centralized pole, and 0 where it points to neither. A dash means the question has no middle answer.

The average of the scores of Q21 and Q22 decides the governance mode: below zero centralized, above zero federated. Only when that average is zero, or neither question is answered, does the average of Q10 to Q13 decide instead. If that average is also zero, both governance modes stay open.

Ranking

From the position on the two axes, the four data ecosystem archetypes are ranked:

  1. the archetype with the project’s application area and governance mode;
  2. the same application area, the other governance mode;
  3. the other application area, the same governance mode;
  4. the other application area, the other governance mode.

If the application area or the governance mode stays open, one ranking is shown for each possibility.
